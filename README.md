# XOR Neural Network

A simple neural network built from scratch in Python using NumPy to learn the XOR logic gate.

I made this project to understand how neural networks actually work, rather than relying on machine learning libraries.

## How it works

- Uses a feedforward neural network with a hidden layer.

- Sigmoid activation function.

- Backpropagation and gradient descent to update weights and biases.

- Trains on all four possible XOR inputs.

## Technologies

- Python
- NumPy

## Results

The network successfully learns XOR and produces predictions close to the expected outputs of 0 and 1.
